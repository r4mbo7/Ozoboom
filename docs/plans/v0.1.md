## Règles

- Celles de [v0.md](v0.md) : une issue, une branche `issue-<numéro>-<slug>`, une pull request qui la ferme, fusion quand la CI est verte ; les couches ne se touchent pas ; un contrat partagé change par une petite pull request additive à part.
- Les contrats de la vague 1 posent des registres (`src/sim/systems/specials.ts`, `src/sim/systems/weapons.ts`) remplis de modules inertes. Une issue de la sim remplace ses modules, un fichier par sorte, et ne touche au registre que sur sa ligne. Le contenu peut ainsi fusionner avant les comportements : `main` reste jouable, les spéciaux sont juste inertes jusqu'à leur issue.
- La première issue de rendu (R1) découpe `src/render/scene.ts` en modules par famille et ne change rien à l'image. Les sept autres travaillent chacune dans son module.
- Le contenu (`src/data/`) est la source des identifiants : une issue de rendu ou d'audio qui a besoin d'un identifiant le prend dans son issue, qui le fixe, et le vérifie dans le contenu fusionné à la fin.
- Quand une issue de contrat fusionne : retirer `blocked` et poser `ready` sur les issues qu'elle débloque (liste dans son texte). Quand toutes les autres ont fusionné : sur P1.
- Les nombres (dégâts, rayons, cadences) sont des points de départ dans `src/data/`, à régler en jouant, jamais dans la logique.

## Lancer un agent sur une issue

Contexte frais, dépôt propre (clone ou worktree), puis :

> Prends l'issue #N du dépôt r4mbo7/Ozoboom. Lis `AGENTS.md`, puis les documents que l'issue indique, puis l'issue. Implémente-la entièrement, `pnpm check` vert, et ouvre une pull request qui la ferme, avec les preuves demandées par ses critères d'acceptation.

Dans une session cloud Claude Code, depuis une copie à jour de `main` : `claude --cloud "<la consigne ci-dessus, avec le numéro>, sur une branche issue-<N>-<slug>"`. Le crochet `SessionStart` de `.claude/settings.json` lance `scripts/cloud-setup.sh`, qui installe Node, pnpm, les dépendances et Chromium dans la session, et ne fait rien sur une machine locale. Les mesures d'images par seconde et les écoutes audio restent à faire en local.
